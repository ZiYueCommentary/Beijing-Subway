# Beijing Subway

Beijing Subway addon expands [Tianjin Metro mod](https://github.com/ZiYueCommentary/Tianjin-Metro) with various things from [Beijing Subway](https://en.wikipedia.org/wiki/Beijing_Subway) in real life.
